what this is

Byte pair encoding starts from 256 raw-byte tokens and repeatedly merges the most frequent adjacent pair. That merge list — learned offline by a 60-line Python trainer on this repo's corpus — is what your browser applies as you type.

This is how LLMs actually see text, minus the word-splitting niceties real tokenizers add. Frames never leave the page; there is no backend.

Colors alternate so you can see where one token ends. Nothing is uploaded — view source.
